# CEPD — SQL

Contains the SQL files used to create, populate, and analyze the Community Events and Participation Database.

## Files

| File / Folder | Purpose |
|---|---|
| `schema.sql` | Creates the eight MySQL tables, including keys and constraints. |
| `seed.sql` | Imports the TSV datasets generated by `generator/generate_seed.py`. |
| `queries/` | Contains the eight individual analytical SQL queries. |
| `queries/all_queries.sql` | Runs all eight queries together. |
| `results/all_queries_verbose.txt` | Saved SQL statements and query results. |

## How to Run

From the repository root, connect to MySQL:

```powershell
mysql -u root -p
```

Create the database and enable local imports:

```sql
SOURCE sql/schema.sql
SET GLOBAL local_infile = ON;
EXIT;
```

Generate the TSV files from PowerShell:

```powershell
python generator/generate_seed.py
```

Reconnect with local imports enabled:

```powershell
mysql --local-infile=1 --default-character-set=utf8mb4 -u root -p cepd_db
```

Import into empty tables. 

```sql
SOURCE sql/seed.sql
```

The seed script sets UTC and displays import results. Confirm 143,014 records with zero skipped rows or warnings. 

Disable local imports and execute the eight queries:

```sql
SET GLOBAL local_infile = OFF;
SOURCE sql/queries/all_queries.sql
```

See the root `README.md` for the complete setup instructions.
