# CEMS — SQL

Directory contains the SQL files used to create, populate, and analyze the Community Event Management System database.

## Files

| File / Folder | Purpose |
|---|---|
| `schema.sql` | Creates the eight MySQL tables, including keys and constraints. |
| `seed.sql` | Imports the TSV datasets generated by `generator/generate_seed.py`. |
| `queries/` | Contains the eight individual analytical SQL queries. |
| `queries/all_queries.sql` | Runs all eight queries together. |
| `results/all_queries_verbose.txt` | Saved output from executing all eight queries, including SQL statements and results. |

## How to Run

From the repository root, connect to MySQL:

```powershell
mysql --local-infile=1 --default-character-set=utf8mb4 -u root -p cems_db
```

Inside MySQL, create the tables in an empty database:

```sql
SOURCE sql/schema.sql
```

Generate the TSV files using the Python generator before importing them. Then load the data:

```sql
SET SESSION time_zone = '+00:00';
SOURCE sql/seed.sql
```

Run all eight analytical queries:

```sql
SOURCE sql/queries/all_queries.sql
```
